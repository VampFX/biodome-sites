# Sunny Sips Lemonade 🍋

A cheerful, mobile-friendly one-page website that helps neighbors find their next cup of lemonade.

## How to Run

Open `index.html` in a web browser. No installation, build step, external files, or CDN dependencies are needed.

## How to Use

- Select **See the Menu** to jump to the drinks and prices.
- Use the page’s navigation links to reach the menu and visit details.
- Check the opening hours and neighborhood location before planning a visit.
- Use **Tab** to move between links and **Enter** to activate them; visible focus indicators help keyboard users navigate.

## Features

- A welcoming hero featuring the **Sunny Sips Lemonade** name and a prominent menu link.
- Classic lemonade and strawberry lemonade, each with a clearly priced example serving size.
- Opening hours and a neighborhood location, with sample details clearly marked for replacement before publishing.
- A short neighborhood-focused story and a fresh-lemonade highlight without unsupported health claims.
- A bright lemon-yellow palette, readable typography, and decorative lemon graphics.
- Responsive layout for mobile and desktop screens without horizontal overflow.
- Semantic page sections, accessible color contrast, visible keyboard focus, and working in-page navigation.
- Self-contained HTML with inline CSS and JavaScript.

## Before Publishing

Replace the marked sample opening hours and location with the stand’s actual details. Confirm the menu prices and serving sizes are accurate.
